# Gilroy

Família completa instalada (Thin a Black, com itálicos) — a Gilroy agora é a
fonte de toda a interface, corpo de texto incluído (`src/fonts.ts` detecta
automaticamente que Regular/Medium/Semibold estão presentes e liga o modo
"full"). Nenhum componente precisa mudar se os arquivos forem trocados ou
completados depois — basta manter o peso no nome do arquivo.

A Gilroy é uma fonte comercial da Radomir Tinkov; o uso aqui segue os
arquivos fornecidos pelo usuário para este protótipo interno. Para
distribuir o produto publicamente depois, confirme a licença (radomir.cc)
antes do lançamento — isso é trabalho do `/replica-deploy`, não desta etapa.
